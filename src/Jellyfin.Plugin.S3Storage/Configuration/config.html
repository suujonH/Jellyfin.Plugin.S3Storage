S3 存储

将本地目录映射到 S3，播放时由客户端直接访问存储服务。

应覆盖影片时长与暂停时间。重新播放时会重新签发授权。
填写挂载目录，或其他需要以公开链接交付的本地目录。
目录必须为空或不存在。挂载失败或卸载后插件会关闭该目录的访问权限（权限 000），以免媒体库扫描把空目录当作文件已被删除；以 root 运行 Jellyfin 时此保护无效。未勾选时使用已由系统管理的挂载。
需与 Worker 的 PLAYBACK_SECRET 一致。

Worker 部署

填写随插件提供的 worker 目录，并先在该目录执行 npm ci。Jellyfin 所在系统需要 Node.js。
填写 * 允许所有来源，或用逗号分隔 Jellyfin Web 的来源（不带路径），例如 https://jellyfin.example.com。修改后需重新部署 Worker。
